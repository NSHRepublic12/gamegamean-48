# Gamegamean-48 🎮

**Gamegamean-48** adalah project sederhana berbasis HTML + CSS **Download Center**.  
Website ini menampilkan daftar game dan software dengan tombol unduh langsung.

## ✨ Fitur
- Navbar transparan dengan link ke Discord, YouTube, dan Grup WA.
- Tampilan cerah, UI compact, responsif untuk mobile.
- Kartu download dengan badge kategori (Game PC / Software).
- Tombol unduh dengan efek hover.
- Favicon custom untuk branding.
